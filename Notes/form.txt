***HTML-এ <form> ট্যাগের action এবং method অ্যাট্রিবিউট দুটি মূলত ব্যবহারকারীর পূরণ করা তথ্য (Data) কোথায় 
এবং কীভাবে সার্ভারে পাঠানো হবে তা নির্ধারণ করার জন্য ব্যবহার করা হয়।


১. action অ্যাট্রিবিউট (কখন এবং কেন লাগে?)
কাজ: ফর্মের Submit বাটনে চাপ দিলে ফর্মে লেখা তথ্যগুলো কোন সার্ভার ফাইলের কাছে বা URL-এ যাবে, তা বলে দেয় action।

কেন লাগে: তথ্যাদি প্রক্রিয়া করার জন্য (যেমন: ডেটাবেজে সেভ করা বা লগইন নিশ্চিত করা) একটি ব্যাকএন্ড প্রসেসিং পেজ প্রয়োজন হয়।
action-এ সেই ফাইল বা লিঙ্ক যুক্ত করা থাকে।

টিপস: যদি action="" খালি রাখা হয় বা না দেওয়া হয়, তবে ফর্ম সাবমিট করলে একই পেজটি রিলোড হবে।
(Single Page Application বা JavaScript দিয়ে ফর্ম হ্যান্ডেল করতে চাইলে action ফাকা রাখা বা
event.preventDefault() ব্যবহার করা হয়)।


২. method অ্যাট্রিবিউট (কখন এবং কেন লাগে?)
কাজ: তথ্যগুলো সার্ভারে কীভাবে বা কোন উপায়ে (HTTP Method) পাঠানো হবে তা ঠিক করে।

প্রধান ২টি প্রকার:

GET (ডিফল্ট):
তথ্যগুলোকে ইউআরএল (URL)-এর শেষে দৃশ্যমান রেখে পাঠায়।
ব্যবহার: সার্চ বার বা অনুসন্ধানের কাজে ব্যবহৃত হয়।
অসুবিধা: পাসওয়ার্ড বা স্পর্শকাতর তথ্যের জন্য নিরাপদ নয়।

POST:
তথ্যগুলোকে ব্রাউজারের পেছনের ব্যাকগ্রাউন্ড বডি (HTTP Request Body) দিয়ে লুকিয়ে পাঠায়।
ব্যবহার: লগইন, রেজিস্ট্রেশন বা ফাইল আপলোডের কাজে ব্যবহৃত হয়।
সুবিধা: পাসওয়ার্ড বা গোপনীয় তথ্যের জন্য পুরোপুরি নিরাপদ।




***HTML <input> ট্যাগে name অ্যাট্রিবিউট দেওয়া অত্যন্ত গুরুত্বপূর্ণ। এর প্রধান কারণগুলো নিচে দেওয়া হলো:
১. সার্ভারে তথ্য পাঠাতে (সবচেয়ে গুরুত্বপূর্ণ কারণ)
যখন কোনো ফর্ম সার্ভারে জমা (Submit) দেওয়া হয়, তখন সার্ভার প্রতিটি ইনপুট 
ফিল্ডের মানকে name = value (Key-Value Pair) আকারে পায়।
যদি ইনপুট ফিল্ডে name না দেওয়া থাকে, তবে ফর্ম সাবমিট করলেও সেই ইনপুটের তথ্য সার্ভারে মোটেই যাবে না।

<!-- name দেওয়া আছে -->
<input type="text" name="username" value="Rahim">
সার্ভারে যেভাবে পৌঁছাবে: username = Rahim

২. রেডিও বাটন (Radio Button) গ্রুপ তৈরি করতে
একাধিক রেডিও বাটনের মধ্যে যেকোনো একটি সিলেক্ট করার সুবিধা দিতে তাদের সবগুলোর name হুবহু এক দিতে হয়। 
name না দিলে বা আলাদা দিলে একসাথে সব রেডিও বাটন সিলেক্ট হয়ে যাবে।
